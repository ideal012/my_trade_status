# สมุดเทรด Forex (my_trade_status)

เว็บบันทึกและวิเคราะห์การเทรด Forex ที่รันบนเครื่องตัวเอง ข้อมูลไม่ออกอินเทอร์เน็ต มีธีมขาวและดำ สลับได้จากปุ่มที่แถบเมนู

## เริ่มใช้งาน

1. ติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน LTS (22.13 ขึ้นไป)
2. ดับเบิลคลิก `start.bat` (ครั้งแรกจะติดตั้งส่วนประกอบเอง) หรือเปิด terminal ในโฟลเดอร์นี้แล้วรัน

   ```
   npm install
   npm start
   ```
3. หน้าเว็บ <http://localhost:3000> จะเปิดขึ้นมาเองในเบราว์เซอร์ (ไม่ต้องการให้เปิดเอง: ตั้ง `NO_OPEN=1`)

โปรแกรมเปิดรับเฉพาะเครื่องนี้ (`127.0.0.1`) เครื่องอื่นในเครือข่ายเข้าไม่ได้ เปลี่ยนพอร์ตได้ด้วย `PORT=3001 npm start`

## หน้าต่าง ๆ

| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวม | กำไรสุทธิ ทุนปัจจุบัน Winrate Profit Factor Max Drawdown, กราฟ Equity, ปฏิทินกำไรรายวัน (กรองสัปดาห์/เดือน/ทั้งหมด/กำหนดเอง) |
| รายการเทรด | เพิ่ม/แก้/ลบเทรด กรอก Entry, SL, TP, Exit, เวลา, กำไร, Commission, Swap, กลยุทธ์ + checklist, tag, อารมณ์, โน้ต และแนบรูปกราฟ (วางด้วย Ctrl+V ได้) |
| วิเคราะห์ | กำไรแยกตามคู่เงิน, Session, วัน, ชั่วโมง, กลยุทธ์, การทำตาม checklist, tag, อารมณ์, Buy/Sell |
| กลยุทธ์ | สร้างกลยุทธ์พร้อม checklist ก่อนเข้าเทรด (หนึ่งข้อต่อหนึ่งบรรทัด) |
| Import | นำเข้าประวัติจากไฟล์ HTML ของ MT5 / MT4 |
| ตั้งค่า | หลายบัญชีและทุนเริ่มต้น, โซนเวลา, ดาวน์โหลด CSV, สำรองฐานข้อมูล |

## Import จาก MT4 / MT5

- **MT5:** แท็บ History → คลิกขวา → Report → HTML
- **MT4:** แท็บ Account History → คลิกขวา → Save as Detailed Report
- ในหน้า Import เลือก "เวลาเซิร์ฟเวอร์โบรกเกอร์" ให้ตรง (ค่าเริ่มต้น GMT+2/+3 ตามเวลาออมแสงสหรัฐ ใช้กับโบรกส่วนใหญ่) แล้วดูตัวอย่างว่าราคา เวลา และกำไรตรงกับในโปรแกรมเทรดก่อนกดนำเข้า
- นำเข้าไฟล์เดิมซ้ำได้ ระบบข้ามไม้ที่มี ticket อยู่แล้ว

> ตัวอ่านไฟล์เขียนจากโครงสร้างตาราง MT4/MT5 มาตรฐานและทดสอบกับไฟล์ตัวอย่างที่สร้างขึ้น ยังไม่เคยทดสอบกับไฟล์จริงจากโบรกเกอร์ของคุณ ถ้าอ่านไม่ได้หรือค่าผิด หน้า Import จะแจ้งเป็นรายแถว (ไม่นำเข้าข้อมูลที่เดา) ให้ส่งไฟล์ตัวอย่าง (ลบเลขบัญชี/ชื่อออกก่อน) มาปรับตัวอ่าน

## สำรองและย้ายข้อมูล

ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` (`journal.db` และ `uploads/` ที่เก็บรูป) คัดลอกโฟลเดอร์นี้เก็บไว้เป็นประจำ หรือกดปุ่มสำรองในหน้า ตั้งค่า (สำเนาฐานข้อมูลอยู่ใน `data/backups/`) ย้ายเครื่องโดยคัดลอก `data/` ไปวางในโฟลเดอร์โปรแกรมเครื่องใหม่ โฟลเดอร์ `data/` ไม่ถูกอัปโหลดขึ้น Git

## ข้อสังเกตเรื่องการคำนวณ

- กำไรสุทธิ = กำไร + Commission + Swap (ใส่ Commission/Swap ติดลบถ้าเป็นค่าใช้จ่าย)
- 1 ไม้ = 1 position; ถ้าปิดบางส่วนเป็นหลายรายการ จะเป็นหลายแถว
- ยังไม่มีการบันทึกฝาก/ถอนเงิน: ทุนปัจจุบัน = ทุนเริ่มต้น + กำไรสุทธิทั้งหมด (ถ้าฝากเพิ่มให้แก้ทุนเริ่มต้นในหน้า ตั้งค่า)
- Pips เป็นค่าประมาณจากชื่อสินค้า (JPY = 0.01, XAU = 0.1, อื่น ๆ = 0.0001) ส่วน RR/R คิดจากราคาจริง จึงไม่ขึ้นกับ pip
- Session แบ่งตามเวลาเปิดไม้ (UTC): Asia 21–07, London 07–12, London/NY 12–16, New York 16–21 ไม่ปรับตามเวลาออมแสง
- เวลาในฐานข้อมูลเก็บเป็น UTC และแสดงตามโซนเวลาที่เลือก
